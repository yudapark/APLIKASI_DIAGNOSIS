Input Manual Perangkat

Gunakan form ini jika merek/model laptop Anda tidak ada di katalog. Data akan diberi label "Input manual pengguna" dan tidak dianggap sebagai spesifikasi resmi terverifikasi.

Cara Menemukan Model Laptop

  • Windows: Tekan Win + R → ketik msinfo32 → lihat System Model.
  • Windows Settings: Settings → System → About → lihat Device name / Model.
  • Label fisik: Cek stiker di bagian bawah laptop atau di sekitar engsel.
  • MacBook: Menu Apple → Mengenai Mac Ini, atau System Information.
  • Situs resmi: Cek halaman dukungan produsen untuk memverifikasi nomor model.

Jangan masukkan nomor seri atau Service Tag—informasi tersebut tidak diperlukan untuk konsultasi awal.
